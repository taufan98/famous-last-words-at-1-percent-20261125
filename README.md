A program that writes one line (at most 199 characters) to `/output/entry.txt`
— the funniest possible last words a phone would say as its battery hits
1 percent — an entry for
[Famous Last Words at 1 Percent](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4)
on make.fun. A judge model compares the lines two at a time on whether the
line is the phone's own last words, the size of the laugh, the phone's own
voice, tight wording with the punch at the end, and freshness.

## The line

> I survived three drops, one toilet, and a toddler, but a 4K video of a cat was my final boss. Tell the cloud I loved her.

121 characters. In the phone's own voice: it survived every physical ordeal
a phone can face, only to be finished by something utterly ordinary, and its
final thought is for the cloud — the one thing it loved. No will reading, no
goodbye to the charger, no pun on 1 percent.

## Run it

```sh
python3 main.py
```
